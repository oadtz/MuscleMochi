# MuscleMochi

เกมเวทเทรนนิ่งบนเว็บที่เล่นด้วยการออกกำลังกายจริงผ่านเว็บแคม มีโค้ช VRoid คอยสอนเหมือนเทรนเนอร์ส่วนตัว เหมาะกับมือใหม่

## โหมดเล่น

- **การผจญภัย** — วิ่งอยู่กับที่เพื่อเดินทางใน 3 ภูมิภาค ต่อยมอนสเตอร์ตามจังหวะเพลง สควอทเพื่อหลบ และเข้าศาลเพื่อฝึกเวทเป็นเซ็ต
- **หอฝึก** — โปรแกรมเวทเทรนนิ่งประจำวัน
- **ฝึกทีละท่า** — ฝึกท่าเดียวพร้อมให้โค้ชช่วยจับฟอร์ม
- **โปรไฟล์ & ประวัติ** — มีหลายผู้เล่น แต่ละคนมีสถิติ ความสำเร็จ และประวัติการเล่น (เก็บใน localStorage)

## วิธีรัน

ต้องเปิดผ่านเซิร์ฟเวอร์ local (กล้องใช้กับ `file://` ไม่ได้):

```bash
python3 -m http.server 8765
```

แล้วเปิด http://localhost:8765 ใน Chrome และอนุญาตให้ใช้กล้อง ยืนห่างกล้องประมาณ 2 เมตร

ถ้าไม่มีกล้อง ใช้คีย์บอร์ดเล่นได้: F/← ต่อยซ้าย, J/→ ต่อยขวา, ↓/S ก้มหลบ, กด Space ค้างเพื่อวิ่ง

## เทคโนโลยี

- [three.js](https://threejs.org/) + [@pixiv/three-vrm](https://github.com/pixiv/three-vrm) สำหรับฉากและโค้ช 3D
- [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) สำหรับจับท่าทางจากกล้อง
- เพลงสร้างสดด้วย Web Audio API

ทั้งเกมอยู่ในไฟล์ `index.html` ไฟล์เดียว โมเดลโค้ชอยู่ใน `assets/` (สร้างด้วย VRoid Studio)
